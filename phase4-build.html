## Key n8n Patterns (Hard-Won)

- No process.env.* — n8n Code nodes block it. Use n8n credentials or hardcode.
- No require('crypto') — also blocked. Use pure-JS HMAC-SHA256.
- No {{ }} expressions in Code nodes. Use $getWorkflowStaticData() or hardcode.
- Always init staticData.metrics per node — nodes may run standalone.
- webhook/ vs webhook-test/ — production uses /webhook/; test requires UI Listen mode.
- n8n API: PUT for workflow updates — only name/nodes/connections/settings fields.
