Phase 4 — Production Hardening

Stable,
Live

This phase turned the prototype newsroom into a credentialized production pipeline. Scout, Writer Hybrid, WF6 SEO, Publisher v3, WF5 Clustering, and WF5.1 Fact Sheets are all active on n8n, writing through Supabase and publishing to Ghost.

What This Phase Fixed
✕
Expired Groq dependency
Writer moved to OpenAI gpt-4o and then Writer v3.1-Hybrid, using the active n8n OpenAI credential path instead of the broken Groq setup.
✕
Hardcoded Ghost publishing
Publisher v3 now uses the n8n Ghost Admin credential, dedup checks, CLAIMING recovery, thumbnail fallback, and stable Supabase updates.
✕
No SEO workflow
WF6 is now active and generates seo_title, meta_description, focus_keyword, slug, and seo_ready through the n8n OpenAI credential.
✕
Unverified side workflows
WF5 Clustering and WF5.1 Fact Sheet were credentialized, redeployed, and validated so the parallel intelligence layer can run safely.
